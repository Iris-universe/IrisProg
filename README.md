# IrisProg

Logiciel de **programmation de festival** ou d'événements : base d'artistes (styles, origine, présentation, cachet, contacts, liens, popularité), propositions par édition et pipeline de booking, **timetable** par glisser-déposer, dossiers PDF, import/export CSV, boîte mail intégrée (IMAP/SMTP, connexion Microsoft, ou Outlook Web intégré).

Recherche et enrichissement automatiques des fiches : Spotify, MusicBrainz, Wikidata, SoundCloud, Resident Advisor, Deezer, Discogs, Last.fm, YouTube (clés facultatives, chiffrées sur la machine).

Rust + [Tauri 2](https://tauri.app), interface HTML/JS. Windows. Compiler : `cargo build --release`.
